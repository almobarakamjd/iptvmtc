# قاعدة بيانات الممثلين — خطوات التركيب على hPanel

هذه الملفات **لا تُرفع لجيت هاب فقط للتوثيق** — يجب رفعها فعلياً لاستضافتك (hPanel) لتعمل، لأن Claude لا يملك اتصالاً مباشراً باستضافتك.

## الخطوات

1. **إنشاء قاعدة بيانات**: من hPanel → قواعد البيانات (MySQL Databases) → أنشئ قاعدة جديدة + مستخدماً بصلاحية كاملة عليها. احفظ: اسم القاعدة، اسم المستخدم، كلمة المرور.
2. **تشغيل الجداول**: افتح phpMyAdmin من hPanel، اختر القاعدة التي أنشأتها، اذهب لتبويب "SQL"، الصق محتوى `schema.sql` بالكامل واضغط تنفيذ (Go).
3. **رفع ملفات PHP**: من File Manager بـhPanel، ارفع `config.php`، `ingest.php`، `search_actor.php` لمجلد فرعي بموقعك (مثلاً `public_html/actors-api/`).
4. **تعديل `config.php`**: افتحه من File Manager وعدّل القيم الأربع (`DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`) بما أنشأته بالخطوة 1، وغيّر `API_TOKEN` لقيمة سرية من عندك.
5. **اختبار سريع**: افتح بالمتصفح
   `https://موقعك/actors-api/search_actor.php?token=رمزك&name=test`
   يجب أن يرجع `{"ok":true,"count":0,"titles":[]}` (طبيعي، القاعدة فارغة بعد).

## الحالة الحالية

- ✅ الجداول والسكربتات جاهزة (`titles`, `actors`, `actor_title`)
- ✅ نقطة استقبال بيانات فيلم واحد (`ingest.php`) وبحث بالممثل (`search_actor.php`)
- ❌ **لم يُربط التطبيق بعد بهذه النقاط** — لا يوجد كود بـmyTv+ يرسل بيانات فعلياً لـ`ingest.php` بعد (لا التسجيل العضوي، ولا الزحف الخلفي، ولا خدمة أندرويد Foreground Service)
- ❌ لم تُختبر هذه الملفات فعلياً على استضافة حقيقية بعد

انظر `readme.md` بجذر المشروع لقسم "مشروع قاعدة بيانات الممثلين" لتفاصيل القرارات والنقاش الكامل.
